Atalhos do Visual Studio Code

Consulte rapidamente as principais combinações de teclas.

Geral

  • Paleta de comandosCtrl + Shift + P
  • ConfiguraçõesCtrl + ,
  • Atalhos de tecladoCtrl + K, Ctrl + S
  • Salvar arquivoCtrl + S
  • Fechar editorCtrl + W

Edição

  • Desfazer / RefazerCtrl + Z / Ctrl + Y
  • Copiar / Recortar / ColarCtrl + C / X / V
  • Selecionar tudoCtrl + A
  • Formatar documentoShift + Alt + F
  • Comentar linhaCtrl + /

Navegação

  • Ir para arquivoCtrl + P
  • Ir para linhaCtrl + G
  • Ir para definiçãoF12
  • Alternar entre editoresCtrl + Tab
  • Pesquisar no arquivoCtrl + F

Seleção e linhas

  • Selecionar próxima ocorrênciaCtrl + D
  • Adicionar cursor acima/abaixoCtrl + Alt + ↑ / ↓
  • Duplicar linhaShift + Alt + ↑ / ↓
  • Mover linhaAlt + ↑ / ↓
  • Excluir linhaCtrl + Shift + K

Visualização

  • Terminal integradoCtrl + `
  • Barra lateralCtrl + B
  • ExploradorCtrl + Shift + E
  • PesquisarCtrl + Shift + F
  • Modo ZenCtrl + K, Z
Os atalhos podem variar conforme o sistema operacional e suas configurações.
